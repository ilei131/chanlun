# 缠论选股系统 - 前端架构设计

## 技术选型

- **框架**: React 18 + TypeScript
- **状态管理**: Zustand / Redux Toolkit
- **UI组件库**: Ant Design 5.x / Material UI
- **图表库**: ECharts (K线图、均线图) + Lightweight Charts (交易量图)
- **路由**: React Router v6
- **HTTP客户端**: Axios
- **构建工具**: Vite
- **样式方案**: Tailwind CSS / CSS Modules

   - GG线: 浅蓝色虚线
   - DD线: 浅蓝色虚线

   - 1买 (第一类买点): 绿色圆圈 ●
   - 2买 (第二类买点): 深蓝色圆圈 ●
   - 3买 (第三类买点): 紫色圆圈 ●

   - 2卖 (第二类卖点): 橙色三角 ▲
   - 3卖 (第三类卖点): 棕色三角 ▲
   - 类买/类卖: 灰色标记

4. **当前信号高亮**
   - 当前买点是绿色圆圈加大+发光效果
   - 当前卖点是红色三角加大+发光效果

### 2. 数据加载与缓存策略

```typescript
// stores/chanlunStore.ts
const useChanlunStore = create((set, get) => ({
  cache: new Map(),

  loadStockData: async (stockId: number, period: string) => {
    const cacheKey = `${stockId}_${period}`;
    const cached = get().cache.get(cacheKey);

    // 缓存30分钟
    if (cached && Date.now() - cached.timestamp < 30 * 60 * 1000) {
      return cached.data;
    }

    const response = await chanlunApi.getChartData(stockId, period);
    get().cache.set(cacheKey, {
      data: response.data,
      timestamp: Date.now()
    });

    set({ ...response.data });
    return response.data;
  },
}));
```

## 性能优化建议

1. **K线图优化**
   - 使用 Canvas 渲染而非 SVG
   - 数据降采样（超过1000点时）
   - 使用 Web Worker 计算指标
   - 懒加载历史数据

2. **列表优化**
   - 虚拟滚动（列表超过100条时）
   - 分页加载
   - 防抖搜索

3. **缓存策略**
   - 股票数据缓存30分钟
   - 缠论结构缓存24小时（除非重新计算）
   - 使用 IndexedDB 本地缓存
